# 0007 — English in the repository

Status: Accepted
Date: 2026-11-07
Deciders: Ezgin (owner)

## Context
Metropolis was English-only; Baret-Stellar's docs were Turkish. The audience of the repo now includes investors' technical reviewers, auditors and future hires.

## Decision
Code, comments, docs, tasks, commit messages and UI source copy are English (translations live in `packages/content`). The owner is addressed in Turkish in chat.

## Consequences
Everyone can read everything. Baret-Stellar's Turkish docs are translated when ported.
